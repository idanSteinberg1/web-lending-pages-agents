# Examples

`web-studio-outcome-hero.html` is a landing page for a web studio built with `/quick-site` and then pushed past "generic". Reference it for:
- **Outcome hero**: business picker → the laptop/phone mockup becomes that business's site (themes via CSS custom properties, container-query-scaled text, auto-cycle that stops on interaction).
- **Live bento**: tiles with small working demos (lead toast, self-scrolling phone, add-to-cart with fly-to-cart).
- **Marquee band**, **tilted browser rail**, **self-building site** process section, **split sticky FAQ**, **chat-style form**.

It's authored as an Artifact body (no html/head tags); wrap it in a document to run it locally.
Version 1 of the same page (a clean but generic stack of hero + 3 cards + band + grid) scored fine on every rule and was still rejected as "looks like everything else". That gap is what art-direction §0 fixes.
